gos.log.warn¶

Write to the script log; rate-limit repeated messages and omit personal data.

Signature¶

gos.log.warn(...)

Contract and usage¶

print("Loaded")
gos.log.debug("State", state)
gos.log.info("Enabled")
gos.log.success("Command completed")
gos.log.warn("Event gap", dropped)
gos.log.error("Cannot continue", reason)

These helpers join arguments with spaces. The five gos.log convenience methods return boolean success. print(...) logs at info level and returns no values; do not use its return value as a success flag.

Structured logging uses a nonempty text value preferentially; otherwise a string message field must be supplied. These are input-field aliases, not two messages emitted together. Keep the final message meaningful and nonempty.

Structured logging:

local ok, error = gos.log.write({
  level = "info",     -- debug, info, success, warn, or error
  tag = "APL",
  text = "Queued Telekinetic Throw", -- message is an alias
  color = "cyan",
})

In the structured level field, "ok" is an alias for "success" and "warning" is an alias for "warn". These are level strings, not additional gos.log.ok or gos.log.warning functions. gos.log.write returns true, nil or false, error. The optional tag is limited to 24 bytes. Messages are sanitized and limited to 1024 bytes; multibyte text can reach that limit in fewer characters. Each script has its own bounded log buffer.
