unit:effects¶

API version: 1.0.0

Read current effect rows and separately marked presentation-only history.

Signature¶

unit:effects(filter)

Contract and usage¶

Resolve the unit in the current world before querying it. A stale unit raises a Lua stale_unit error; this is distinct from a current unit returning a pending or unavailable effect observation. and status

Effect queries return the latest completed observation for that unit. They are snapshots, not synchronous reads.

status == "ready" means the latest valid completed poll, not a synchronous read at the time of the Lua call. Routine queued refreshes and combat effect notifications do not revoke that sample. Notifications only prioritize the next poll, so applications/removals become visible at the next publication. Timers age from their original sample anchor between polls.

Always check status and completeness: a complete ready observation proves presence/absence as of that poll. First capture, invalid owners/worlds, and actual acquisition failures remain distinguishable from an empty list. A missing execution opportunity is a scheduling wait, not an acquisition failure.

unit:effects(filter?)¶

Returns the matching observed rows without merging same-name variants:

{
  status = "ready" | "pending" | "unavailable",
  reason = string,
  age_ms = integer | nil,
  last_known_age_ms = integer | nil,
  truncated = boolean,
  last_known_truncated = boolean,
  items = {
    {
      definition_key = "effectdef:<16 uppercase hex digits>" | nil,
      name = string,
      name_source = "client" | "core",
      freshness = "current",
      has_charges = boolean,
      charge_conflicted = boolean,
      stacks = integer | nil,
      has_timer = boolean,
      remaining = number | nil,
      has_duration = boolean,
      duration = number | nil,
      kind = "buff" | "debuff" | "passive" | "other",
      has_ownership = boolean,
      mine = boolean
    }
  },
  last_known_items = {
    {
      definition_key = "effectdef:<16 uppercase hex digits>" | nil,
      name = string,
      name_source = "client" | "core",
      freshness = "last_known",
      has_charges = boolean,
      charge_conflicted = boolean,
      stacks = integer | nil,
      has_timer = boolean,
      remaining = number | nil,
      has_duration = boolean,
      duration = number | nil,
      kind = "buff" | "debuff" | "passive" | "other",
      has_ownership = boolean,
      mine = boolean
    }
  }
}

The optional filter accepts name, kind, definition_key, timed, and charged with the same semantics as the singular query. A ready empty items table proves no matching current captured effect only when truncated == false. Pending, unavailable, or truncated observations do not prove absence.

last_known_truncated reports capacity loss only in presentation continuity. It does not weaken an otherwise complete current observation and must not be used as a gameplay-availability gate.

items is always an array. It is populated only when status is ready; otherwise it is empty, which is not proof of absence. last_known_items is also always an array. last_known_items is additive presentation-only continuity for the same observed unit. It may be populated while an observation is pending/unavailable or while current enrichment is incomplete. Its timers are aged from their authoritative sample and removed at zero; those rows never make the observation ready and must not drive rotations, targeting, or tactical action cues. Unavailable observations remain unavailable for every unit; do not guess missing state.

local debuffs = target:effects({ kind = "debuff", timed = true })
if debuffs.status == "ready" then
  for _, effect in ipairs(debuffs.items) do
    if effect.mine then
      gos.log.debug(effect.name, effect.remaining or "untimed")
    end
  end
end

Exact effect identity¶

definition_key identifies an effect definition, not an effect instance, a unit, or a castable ability. Same-name variants can have different keys. Treat keys as opaque and use an observed value; do not manufacture one. A key never makes a pending or historical row current. Both query forms accept a definition_key filter. To query only by key, pass an empty name to unit:effect("", { definition_key = observed_key }).

Plural rows expose has_duration and, when available, total duration in seconds. Duration is independent of remaining; do not estimate it from the first timer value you happen to see.
