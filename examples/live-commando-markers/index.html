Standalone stealth: persistent position markers¶

Live-script excerpt - from stealth_event_detector.lua, used by the standalone Stealth Detector package. The function below is copied unchanged.

The detector draws two frame-local circles at each captured position until its record expires. The same pattern works for encounter notes, last-seen locations and timed world annotations.

View or save the excerpt

Integration fragment, not a standalone rotation

This method belongs to the detector object. It requires self.markers, self.stats, FRAME_TTL, and the module's finite and valid_position helpers. Each marker contains position, expiresAt, eventName, and serial. Keep the marker collection bounded in the producer; do not enable this excerpt by itself.

Code from the live script¶

function Detector:draw_markers(now, options)
    now = finite(now) and now or 0.0
    options = type(options) == "table" and options or {}
    for handle, marker in pairs(self.markers) do
        if not finite(marker.expiresAt) or marker.expiresAt <= now then
            self.markers[handle] = nil
        elseif options.enabled ~= false and valid_position(marker.position) and
            gos.overlay and type(gos.overlay.draw_circle) == "function" then
            local color = marker.eventName == "Force Camouflage" and
                "orange" or "magenta"
            local suffix = tostring(marker.serial)
            for _, ring in ipairs({ { "o", 0.8, 48, 3 }, { "i", 0.18, 24, 2.5 } }) do
                local ok, accepted = pcall(gos.overlay.draw_circle,
                    "stl:" .. ring[1] .. ":" .. suffix, {
                        at = { world = marker.position },
                        world_radius = ring[2],
                        color = color,
                        segments = ring[3],
                        thickness = ring[4],
                        ttl = FRAME_TTL,
                        frame = true,
                    })
                if ok and accepted ~= false then
                    self.stats.markerAccepted = self.stats.markerAccepted + 1
                else
                    self.stats.markerRejected = self.stats.markerRejected + 1
                end
            end
        end
    end
end

How to use the pattern¶

A top-level owner supplies now = gos.time_ms() / 1000. The observer records positions before units disappear; this draw method uses those copied coordinates rather than retaining a GosUnit.

Call detector:draw_markers(now, { enabled = true }) on the existing detector instance. Use the same clock for creation and expiry. Stable IDs replace previous frame drawings. Passing enabled = false removes the callback's marker contribution on its next publication.

world_radius = 0.8 is eight metres at the current world scale. The outer and inner circles make a single position easy to see. Orange distinguishes Force Camouflage; magenta is the other marker color. This is a last-observed position, not proof of where a hidden player is now.
